        Document.prototype/Element.prototype.querySelectorAll 메서드는
            인수로 전달한 CSS선택자를 만족시키는 모든 요소 노드를 탐색하여 반환한다.
            여러 개의 요소 노드 객체를 갖는 DOM 컬렉션 객체인 NodeList 객체를 반환한다.
